# MuleSoft Premier Onboarding Dashboard

A personal productivity dashboard built to manage and track MuleSoft Premier Onboarding cases in real time.

## What it does

- Displays all open onboarding cases with age, status, and sub-status
- Flags overdue (>29 days) and at-risk (15–29 days) cases
- Tracks last customer outreach and highlights stale cases
- Logs customer calls (Kickoff, Platform Overview, Success Path, 90-Day Check-in)
- Shows SLO compliance (48h first outreach)
- Expandable case rows with comments and internal notes
- KPI summary chips and 3 live charts (status, sub-status, age by account)
- Meeting banner for upcoming kickoff calls
- Filter and sort by status, stage, and risk level

## Built with

- Vanilla HTML, CSS, JavaScript
- Chart.js
- Salesforce CLI (data source)
- localStorage for call/follow-up state
